# Flowhaven Brand & Domain Direction

## Brand name
**Flowhaven**

A single-word name that suggests sanctuary, movement, softness, and arrival. It keeps the "flow" concept while widening the brand beyond only wine or yoga.

## Tagline
**Where movement meets the vine.**

Spanish:
**Donde el movimiento se encuentra con la vid.**

## Logo direction
The current mark is a minimal circular emblem:
- dark soul-green field
- gold vine/stem centerline
- two soft wave arcs suggesting breath, movement, horizon, and sanctuary

Use cases:
- favicon
- header mark
- footer brand lockup
- social avatar

## Domain recommendation
Primary shortlist:
1. `flowhaven.co` — concise, premium, startup-friendly
2. `flowhaven.es` — strong Spanish/Málaga location fit
3. `flowhavenretreat.com` — clearer but longer

Recommended launch setup:
- Use `flowhaven.co` as primary if available
- Redirect `flowhaven.es` to localized Spanish landing page (`/es`)
- Keep `NEXT_PUBLIC_SITE_URL=https://flowhaven.co` in production

## Positioning line
Flowhaven is an immersive couples sanctuary in Málaga where restorative movement, Andalusian wine, and coastal dining unfold as one intimate day.
